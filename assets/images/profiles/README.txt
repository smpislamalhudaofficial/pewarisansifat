Jika ingin mengganti foto:
- Simpan foto di folder assets/images/profiles/.
- Gunakan nama file yang sama persis.
- Pastikan file benar-benar berformat JPEG (.jpg), bukan PNG yang hanya diganti nama ekstensinya.
- Rekomendasi rasio foto: portrait; bingkai aplikasi tetap 4:5.
- Foto ditampilkan utuh (tidak dipotong) di dalam bingkai rounded rectangle 4:5.

Jika nama atau ekstensi file berbeda, sesuaikan juga properti image pada data developerProfiles di js/app.js.
