PANDUAN GAMBAR ILUSTRASI QUIZ

Simpan gambar ilustrasi untuk setiap soal di folder ini dengan nama file berikut:
- quiz-01.png sampai quiz-20.png

Contoh:
assets/images/quiz/quiz-01.png
assets/images/quiz/quiz-02.png
...
assets/images/quiz/quiz-20.png

Setiap placeholder pada halaman Quiz akan otomatis diganti dengan gambar apabila file yang sesuai sudah tersedia. Jika file belum ada, placeholder tetap ditampilkan sehingga tata letak soal tidak kosong.

Rekomendasi:
- Rasio gambar: 4:3 atau 16:9.
- Resolusi: minimal 1200 × 900 piksel untuk 4:3 atau 1600 × 900 piksel untuk 16:9.
- Format: PNG atau WebP. Jika memakai WebP, ubah ekstensi pada properti image di js/app.js.
- Gunakan ilustrasi yang relevan dengan konteks soal, bukan hanya gambar dekoratif.
- Untuk diagram genetika, pastikan simbol alel, arah untai DNA/RNA, dan label ilmiah terbaca jelas.
- Hindari teks panjang di dalam gambar; narasi dan pertanyaan sudah disediakan di aplikasi.
