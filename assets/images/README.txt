Rekomendasi:
- Resolusi: lebar minimal 1600 piksel.
- Rasio: 16:9 untuk diagram/ilustrasi materi; 4:3 atau 3:2 untuk karakter/keluarga.
- Format: PNG atau WebP. Jika menggunakan WebP, ubah ekstensi file dan nama referensi pada js/app.js.
- Gaya: ilustrasi edukasi yang bersih, jelas, konsisten, dan sesuai materi biologi.
- Hindari memasukkan paragraf atau label teks panjang ke dalam gambar. Teks penjelasan lebih baik tetap ditulis di halaman HTML agar mudah dibaca.
- Untuk gambar karakter manusia, gunakan pakaian sopan/modest sesuai arahan desain MPI.

Jika gambar belum tersedia, aplikasi otomatis menampilkan ilustrasi SVG pengganti.
Anda cukup menyalin gambar ke folder ini dengan nama yang sesuai; tidak perlu mengubah kode.
